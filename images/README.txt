MASOMO BROO — THREE GRADE 8 CROSSWORDS
========================================

Included:
- index.html: menu linking to all three crossword puzzles
- crossword-1-communication.html: Business Communication
- crossword-2-visual-programming.html: Visual Programming
- crossword-3-composite-ceramics.html: Composite and Ceramic Materials
- crosswords.css: shared dark/amber responsive theme
- crosswords.js: shared crossword logic

HOW TO USE
1. Extract all files into the same folder.
2. Open index.html in a browser.
3. To add them to your existing Masomo Broo site, link the activity cards to the relevant HTML filename.
4. The "Back to activities" link points to choose.html. Change that link if your chooser page has another filename.

Features: Across and Down clues, numbered crossing grid, keyboard entry, answer checking, progress indicator, reveal answers and reset.

Content is based on the uploaded Grade 8 Pre-Technical Studies notes. Clues are paraphrased for a game and are not an official assessment.
